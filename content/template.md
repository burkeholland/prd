Read the same template used in the editor, with questions to help you make each decision. The [completed example PRD](/sample) is a separate reference, not a format you need to follow.

Choose the format that matches the handoff:

- [Markdown](/downloads/prd-template.md): Editable plain text for source control, issue descriptions, or handing to an agent.
- [Word (`.docx`)](/downloads/prd-template.docx): Editable in a word processor for collaborators who review or comment there.
- [PDF](/downloads/prd-template.pdf): Fixed-layout reading, sharing, printing, or approval where editing is not expected.
- [Draft backup](/): The editor's lossless `.prd.json` reopen/import format for exact in-progress fields; use **Download draft backup** under **Draft controls**. It is not a finished document export.
